# Dot Files

This is a backup of my dot files just in case something happens to my computer.

Files are saved to this repo as if the root directory were `~`

Examples

| File | Path |
|------|------|
| .zshrc | ~/.zshrc |
| .config/nvim/init.vim | ~/.config/nvim/init.vim |
